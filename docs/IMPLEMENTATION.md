# Implementation note

Built with React, strict TypeScript, Vite, and Tailwind CSS v4 through `@tailwindcss/vite`. Semantic HTML and small React components handle navigation, the native dialog gallery, search, and contact validation. System fonts, local WebP variants, and native browser form/dialog behavior keep dependencies and network requests small. Prettier and ESLint support readable code; Playwright and axe verify browser behavior.

One central design decision was to make the agent's dated sales evidence a clear editorial feature: a large kitchen photograph sits beside a navy panel explicitly labelled “A look back at 2021.” This makes the original $28.5 million / nearly 90 clients claim easier to scan without making it appear to be a current-year statistic. Buyer and seller guidance follow as smaller paired stories.

The palette takes its navy cue from The Ridge Realty Group logo and Marci's portrait, with ivory and restrained bronze supporting the landscape photography. Visible desktop navigation and an accessible mobile menu shorten the path to search and contact. The gallery does not auto-advance, so visitors control its pace.

This is a proposed design rationale to review and adapt, not a claim that the applicant has already made these decisions independently. Before the interview, choose one change you would make and explain why.
